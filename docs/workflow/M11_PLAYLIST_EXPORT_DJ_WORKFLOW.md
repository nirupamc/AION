## Goal

## Saved Flow Model

### SavedFlow
- `id`, `name`, `description`
- `start_track_id` (FK → tracks, nullable)
- `target_track_count`, `energy_shape`
- `constraints_json` (generation parameters for reproducibility)
- `overall_sequence_score`, `average_transition_score`, `minimum_transition_score`
- `optimizer_version` ("m9-beam-v1"), `transition_model_version` ("m8-transition-v1")
- `status` ("ok" | "insufficient_candidates")
- `created_at`, `updated_at`

### SavedFlowTrack
- `flow_id` (FK → saved_flows, CASCADE)
- `track_id` (FK → tracks, CASCADE)
- `position` (unique per flow)
- Denormalized: `title`, `artist`, `bpm`, `camelot`, `energy`, `dominant_mood`, `dominant_vibe`
- Transition: `transition_score`, `transition_components_json`, `transition_reasons_json`, `transition_warnings_json`

### FlowExport
- `flow_id` (FK → saved_flows, CASCADE)
- `provider`, `external_playlist_id`, `external_playlist_url`, `external_playlist_name`
- `exported_track_count`, `skipped_track_count`, `skipped_tracks_json`
- `status`, `error_summary`

## Persistence
- Migration: `0004_saved_flows.py` (Alembic, upgrade/downgrade clean)
- CASCADE delete: flow tracks and exports removed when flow deleted
- Unique constraint: `(flow_id, position)` prevents duplicate positions
- Indexes: `ix_saved_flows_created`, `ix_saved_flow_tracks_flow`, `ix_saved_flow_tracks_track`, `ix_flow_exports_flow`

## Reproducibility
- Constraints JSON captures all generation parameters (mood, vibe, bpm_range, etc.)
- Optimizer version and transition model version recorded
- Regenerated flows may differ if upstream metadata changes — documented

## Spotify Export

### Endpoint
`POST /flows/{id}/export/spotify`
```json
{
  "playlist_name": "AION — Peak Build",
  "description": "...",
  "public": false
}
```

### Response
```json
{
  "provider": "spotify",
  "playlist_id": "...",
  "playlist_url": "...",
  "exported_track_count": 10,
  "skipped_track_count": 0,
  "skipped_tracks": []
}
```

### Batching
Tracks added in batches of 100 (Spotify API limit).

### Error Handling
- Token refresh on 401/403
- Rate limiting with retry
- Missing Spotify provider URI → reported in skipped_tracks
- Partial add failure → reported with batch info
- Export history recorded regardless of success/partial status

### Known Issue
Spotify returns 403 for playlist creation despite correct scopes. This is likely a Spotify Developer Dashboard configuration issue — the app may need `playlist-modify-private` scope enabled and the user may need to re-authorize. The token refresh succeeds, but the API still rejects the request.

## JSON Export

### Endpoint
`GET /flows/{id}/export/json`

Returns full `SavedFlowDetail` with sequence and export history.

## Filename Sanitization
- Remove `<>:"/\|?*` and control characters
- Strip leading/trailing dots and spaces
- Collapse whitespace
- Truncate to 200 chars
- Fallback: "aion-flow"

## Export History
Every export attempt (success or failure) is recorded in `flow_exports` with:
- provider, external IDs/URLs
- exported/skipped counts
- skipped track details
- status and error summary

## API Endpoints

| Method | Path | Description |
|--------|------|-------------|
| GET | `/flows` | List saved flows |

| POST | `/flows` | Save a generated flow |
